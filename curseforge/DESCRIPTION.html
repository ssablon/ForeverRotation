Forever Rotation (Multi language)

Created by Vohnka — https://wow-forever.fr

Rotation helper for WoW Forever Classic (camelot client, interface 16001). The interface is translated in 11 languages (English fallback).

It shows the next three spells on a HUD and flashes a skull on the matching action-bar button. It also tracks heals, long defense buffs, interrupts, purges, cleanses, and weapon imbues. This is not a bot — you still press the keys.

What you see

  • Next ability, then the two after that
  • White skull on the button to press
  • Green / blue / red flashes for heal, defense, and weapon
  • Classic swing, dual-wield, auto-shot, and energy timing

Spellflash colors

  • White — next ability
  • Green — heal (only when someone is missing health)
  • Blue — long defense buff (blessings, auras, buffs > 1 min)
  • Red — weapon enchant / poison

Profiles and classes

Base · PvE · PvP · Custom — each has its own lists. A reset touches the current profile only.

Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock, Druid.

Optional: hide the HUD while idle, bar-only suggestions, auto PvE/PvP profile, group dispel, Classic physics cues.

Install

  1. Close the game client.
  2. Copy the WoWForeverRot folder into World of Warcraft\_classic_beta_\Interface\AddOns\
  3. Restart → Addons → enable Forever Rotation.

The CurseForge app often installs into official Classic. On Forever, unzip by hand into _classic_beta_.

Commands

/wfr, /foreverrot, or /foreverrotation

  • /wfr lock / unlock — lock or move the HUD
  • /wfr menu — options (add, toggle, reorder)
  • /wfr profile / base / pve / pvp / custom
  • /wfr mode — Auto / Single / AoE / Burst
  • /wfr role — dps / tank / healer

Minimap button: left-click = options, right-click = lock.
