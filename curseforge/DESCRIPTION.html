Aide de rotation pour WoW Forever (combat Classic Era, client camelot). HUD des 3 prochains sorts et flash tête de mort sur les barres. Ce n’est pas un bot : tu appuies toujours sur les touches.

Rotation helper for WoW Forever. Next-3 HUD + skull spellflash. Not a bot.

Installation

  1. Ferme le client.
  2. Copie le dossier WoWForeverRot dans
    World of Warcraft\_classic_beta_\Interface\AddOns\
  3. Relance → Addons → coche WoW Forever Rot.

L’app CurseForge installe souvent dans Classic officiel. Sur Forever, dézippe à la main dans _classic_beta_.

Couleurs du flash

  • Blanc — prochain sort
  • Vert — soin (seulement si quelqu’un manque de vie)
  • Bleu — buff défense (bénédictions, auras, buffs > 1 min)
  • Rouge — enchant / poison d’arme

Profils

Base · JCE (PvE) · JCJ (PvP) · Customs — chacun a ses listes. Reset = profil actuel seulement.

Commandes

/wfr ou /foreverrot

  • /wfr lock · unlock — verrouiller / bouger le HUD
  • /wfr menu — options (ajouter, cocher, réordonner)
  • /wfr profile · base · jce · jcj · custom
  • /wfr mode — Auto / Mono / AoE / Burst
  • /wfr role — dps / tank / soins…

Clic gauche sur le bouton minimap = options. Clic droit = verrou.

Classes

Guerrier, Paladin, Chasseur, Voleur, Prêtre, Chaman, Mage, Démoniste, Druide.
