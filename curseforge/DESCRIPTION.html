Rotation helper for WoW Forever (Classic Era combat, camelot client). Next-3 ability HUD and skull spellflash on your action bars. This is not a bot — you still press the keys.

Install

  1. Close the game client.
  2. Copy the WoWForeverRot folder into
    World of Warcraft\_classic_beta_\Interface\AddOns\
  3. Restart → Addons → enable WoW Forever Rot.

The CurseForge app often installs into official Classic. On Forever, unzip by hand into _classic_beta_.

Spellflash colors

  • White — next ability
  • Green — heal (only when someone is missing health)
  • Blue — defense buff (blessings, auras, buffs > 1 min)
  • Red — weapon enchant / poison

Profiles

Base · PvE · PvP · Custom — each has its own lists. Reset affects the current profile only.

Commands

/wfr or /foreverrot

  • /wfr lock · unlock — lock / move the HUD
  • /wfr menu — options (add, toggle, reorder)
  • /wfr profile · base · jce · jcj · custom
  • /wfr mode — Auto / Single / AoE / Burst
  • /wfr role — dps / tank / healer…

Minimap button: left-click = options, right-click = lock.

Classes

Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock, Druid.
