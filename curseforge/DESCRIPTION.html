Forever Rotation (Multi language)

Rotation helper for WoW Forever Classic (camelot client, interface 16001).

A HUD of the next three abilities, a skull flash on the matching action-bar button, plus heals, long defense buffs, interrupts, purges, cleanses and weapon imbues. This is not a bot — you still press the keys.

What you see

  • Next spell, then the two after that
  • White skull on the button to press
  • Green / blue / red flashes for heal, defense, weapon
  • Classic swing, dual-wield, auto-shot and energy timing

What it does not do

  • Never casts, never clicks for you
  • Never reads other players' keys
  • Reset only touches the current profile
  • UI text in 11 languages, English fallback

Spellflash colors

  • White — next ability
  • Green — heal (only when someone is missing health)
  • Blue — defense buff (blessings, auras, buffs > 1 min)
  • Red — weapon enchant / poison

Profiles & classes

Base · PvE · PvP · Custom — each has its own lists. Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock, Druid.

Hide the HUD while idle, bar-only suggestions, auto PvE/PvP profile, group dispel, and Classic physics cues when you want them.

Install

  1. Close the game client.
  2. Copy the WoWForeverRot folder into
    World of Warcraft\_classic_beta_\Interface\AddOns\
  3. Restart → Addons → enable Forever Rotation.

The CurseForge app often installs into official Classic. On Forever, unzip by hand into _classic_beta_.

Commands

/wfr, /foreverrot, or /foreverrotation

  • /wfr lock · unlock — lock / move the HUD
  • /wfr menu — options (add, toggle, reorder)
  • /wfr profile · base · pve · pvp · custom
  • /wfr mode — Auto / Single / AoE / Burst
  • /wfr role — dps / tank / healer…

Minimap button: left-click = options, right-click = lock.
